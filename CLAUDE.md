# Repository note

This repository contains two unrelated projects.

- **Root** (`app/`, `components/`, `hooks/`, …) is an Expo / React Native
  battery-and-charging app. This is the original project.
- **`NLLens/`** is a native iOS app (Swift, SwiftUI, App Intents) that
  translates Dutch app screens to English. It shares no code with the Expo app
  and is not built by it.

They are independent. Work on one without touching the other, and see
`NLLens/CLAUDE.md` before making changes there.
